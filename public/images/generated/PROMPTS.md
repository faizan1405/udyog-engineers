# Equipment Visual Asset Prompts & Style Guide
This directory contains the temporary photorealistic product image placeholders for Udyog Engineers (Redesign R1.3).

All assets are 1200x900 `.webp` images photographed / rendered in unified commercial catalogue quality with studio lighting, neutral light cyclorama backgrounds, gentle contact shadows, and no fake branding or HUD overlays.

Refer to `docs/IMAGE_GENERATION_PROMPTS.md` for full prompt specifications and regeneration guidelines.
